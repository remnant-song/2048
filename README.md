# 🎮 控制台版 2048（C++ 实现）

一个用 **C++ 编写的简易控制台版 2048 游戏**，支持即时键盘输入（无需回车）、自动刷新界面、计分系统等功能。

## 🧩 功能特点

- ✅ 4×4 棋盘逻辑，与原版 2048 一致  
- ✅ 使用 `WASD` 控制上下左右移动  
- ✅ 无需回车即可即时响应输入（基于 `_getch()`）  
- ✅ 每次合并自动计算得分  
- ✅ 屏幕实时刷新显示游戏界面  
- ✅ 游戏结束自动检测  
- ✅ 程序简单、易扩展，可添加存档或最高分功能

## 🧮 核心逻辑简介

1. **棋盘数据结构：**
   ```cpp
   vector<vector<int>> grid(4, vector<int>(4, 0));
````

使用二维 `vector` 表示 4×4 棋盘。

2. **随机生成新方块：**

   * 在空位随机生成 `2`（90%）或 `4`（10%）。

3. **移动与合并：**

   * 将一行压缩（去除 0）。
   * 合并相邻相等的数。
   * 自动计算得分：

     ```cpp
     score += merged_value;
     ```

4. **游戏结束判断：**

   * 棋盘无空位且无可合并的相邻数时，游戏结束。
